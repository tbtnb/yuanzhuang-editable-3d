# 东窗小筑 · East Window Studio

根据用户提供的客厅照片制作的温馨三维布局小游戏。只重建照片中可见的客厅，不包含原始照片。

在线页面：https://tbtnb.github.io/yuanzhuang-editable-3d/east-window/

## v3：补充视角与手机交互修订

- 白色炮台造型立式设备已由用户确认为音响，独立对象 ID 为 `turretAudio`。模型采用球形头部、圆形网罩、细支杆和圆底座，没有风扇叶片。不推测品牌。
- 棕色方盒仍是投影仪，为兼容旧存档保留其历史 ID `speaker`。它和白色音响是两个独立可拖动对象。
- 补上幕布旁圣诞树、蕨类四脚花架、绣球花架；将金色三头吊灯移到幕布前方，增加顶部吊杆。
- 新视角的厚叶直立植物使用椭圆厚叶与白色方盆表现，标注“疑似橡皮树类，待确认”，不把外形判断当作已确认品种。
- 东窗改为中部黑框窗、下方飘窗和两侧落地窗帘，不再表现为整面通长玻璃窗。调整工作台、沙发、茶几和幕布之间的相对比例。
- 初始房间约 **5.8 × 6.6 × 2.85 m**，仅为照片估算。场景设置可分别修改东西宽度和工作台至幕布方向的总进深；改变边界不拉伸家具模型。
- 增加“新视角”相机按钮，方便从补充照片的方向检查房间。
- 手机详情默认隐藏，选中或拖动物品不会自动打开；点击底部“详情”或物品标签才展开。布局与详情面板均可通过顶部收起按钮、底部开关或点击外侧关闭。关闭详情保留选中状态。
- 手机底部操作栏独立于房间画布，展开面板不会把关闭按钮遮住。适配窄屏与手机横屏，隐藏面板不接受键盘焦点。

## 操作

直接拖动物品进行 X-Z 平面移动，高度锁定。拖动空白处环绕，滚轮缩放；空格或鼠标右键拖动平移视角。手机单指拖动物品，双指缩放。俯视模式便于摆放。

选中后 R 旋转 15°，Shift+R 反转。方向键移动 10 cm，Shift+方向键移动 1 cm。Delete 收起，Esc 取消选择，Ctrl/Command+Z 撤销，Ctrl/Command+Shift+Z 重做。

48 个可选对象，含 16 个植物/花材对象。家具及花架上的物件随承载家具移动，也可独立调整。植物和部分摆件可切换到地面、飘窗、桌面、柜面或花架；拖动不改变高度。

四套预设：新视角还原、追光小森林、幕布电影夜、清爽留白。另有晨光/日间/暖夜、重叠提醒、植物身份校正与复制、幕布展开/收起、投影示意和镜头朝向控制。

## 保存与兼容

自动保存和三个收藏槽只存在当前浏览器，不跨设备同步。导出 JSON 可备份布局，导入可恢复；拍照按钮导出 PNG。

v3 布局包含房间宽度与进深参数。读入 v1/v2 数据时迁移：命名预设采用新视角校准坐标；手动布局按相对位置转换。首次迁移自动保存前，将旧数据保留到 `east-window-studio.before-v3`。旧收藏槽和 JSON 也可导入。浏览器禁止本地存储时请导出文件保存。

## 重建边界

尺寸、门窗位置和家具比例未经测量，不是施工图。仅根据有限照片调整相对关系，准确复原仍需实测尺寸。茶具按组建模，未逐一复刻极小摆件；窗外楼体是泛化示意，不复原住址。

植物只按照片外形识别并标注置信度。九盆窗台植物使用八类不同外形，不表示已确认八个物种；小盆、花材及真假植物状态保持待确认。

灯光只表现氛围，不计算真实照度、日照时间或楼体遮挡。投影画面不模拟真实投射比、侧投校正、光路或遮挡，不能据此确定实机安装位置。植物背景资料链接见网页使用说明。

## 本地运行与文件

无构建步骤、无第三方依赖。打开 index.html，或在本目录运行 `python -m http.server 8000` 后使用浏览器访问本地服务器。

加载顺序：`engine.js` → `room.js` → `compat.js` → `revision.js` → `room-v3.js` → `app.js` → `mobile-ui.js`。

- `engine.js` / `compat.js`：WebGL 与 Canvas 兼容渲染。
- `room.js` / `revision.js`：初始模型、植物图鉴、投影系统及原有修订。
- `room-v3.js`：新视角建筑、音响、装饰树、花架、预设和存档迁移。
- `app.js`：拖放、承载面、历史、保存和界面逻辑。
- `mobile-ui.js` / `mobile-ui.css`：手机面板状态、显式详情与收起控制。
- `index.html` / `styles.css` / `revision.css`：入口和原有界面样式。

模型和纹理均在本地程序生成。页面不加载原始室内照片、外部字体、分析追踪或第三方模型。

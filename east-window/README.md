# 东窗小筑 · East Window Studio

根据客厅照片制作的温馨三维布局小游戏。只重建照片中可见的客厅，不包含原始照片。

在线页面：https://tbtnb.github.io/yuanzhuang-editable-3d/east-window/

## 操作

直接拖动物品进行 X-Z 平面移动，高度锁定。拖动空白处环绕，滚轮缩放；空格或鼠标右键拖动平移视角。手机单指拖动物品，双指缩放。俯视模式便于精准摆放。

选中后 R 旋转 15°，Shift+R 反转。方向键移动 10 cm，Shift+方向键移动 1 cm。Delete 收起，Esc 取消选择，Ctrl/Command+Z 撤销，Ctrl/Command+Shift+Z 重做。

43 个可选对象，含 16 个植物/花材对象。家具表面的物件随承载家具移动，也可独立调整。植物和部分摆件可切换到地面、飘窗、桌面或柜面；拖动不改变高度。提供照片原位、追光小森林、观影围合、清爽留白四套预设，晨光/日间/暖夜三种视觉氛围，以及重叠提醒、植物品种校正和复制。

自动保存与三个收藏槽只存在当前浏览器，不跨设备同步。导出 JSON 可备份布局，导入可恢复；拍照按钮导出 PNG。

## 重建边界

房间暂按 7.2 × 5.8 × 2.85 m 估算，家具尺寸和门窗位置不是实测数据。墙窗与飘窗结构固定。茶具按组建模，未精确复刻每个微小摆件。窗外楼体为泛化示意，不复原住址。

植物识别基于照片外形，包含置信度与人工校正；小盆、花材和真假植物状态保持待确认。灯光只表现氛围，不做真实照度、日照时间或楼体遮挡计算，不可作为养护和施工的定量依据。植物背景资料链接见网页使用说明。

## 本地运行与文件

无构建步骤、无第三方依赖，打开 index.html 即可；也可以在本目录执行 `python -m http.server 8000` 后访问本地服务器。

- `engine.js`：WebGL 几何、阴影、相机及物品拾取。
- `compat.js`：无 WebGL 时使用的 Canvas 软件三维渲染器。
- `room.js`：程序化模型、纹理、植物图鉴和预设坐标。
- `app.js`：拖放、承载面、历史、存档、导入导出和界面逻辑。
- `styles.css`、`index.html`：响应式界面。

所有纹理和模型本地生成，不请求外部资源、字体或分析追踪。浏览器禁止本地存储时请导出布局文件。

## 测试范围

使用 Chromium 自动化检查了桌面 1512×982 与手机 393×852 布局，四个预设、平面拖动、子物件跟随、撤销重做、旋转、植物承载面与品种切换、复制、边界约束、JSON 导出/导入及错误恢复、收藏与 PNG 导出；手机另测单指拖动和双指缩放。

测试环境无 WebGL，实际画面测试使用 Canvas 兼容路径；WebGL 硬件路径未经该环境实机验证。自动保存逻辑在测试用存储适配器中验证，真实浏览器的存储策略仍由使用者环境决定。
